# PRD: vid-cut — 講座録画の自動カット編集ツール

**ステータス:** 承認済み
**作成日:** 2026-10-03
**入力:** [kickoff](./references/kickoff.md)、[ADR-001](./adr/ADR-001-language-and-stack.md)

## 1. 問題定義

### 背景

Udemy 講座用に録画した mov（画面録画 + 日本語ナレーション）を、Premiere Pro で手作業でカットしている。
録画中は言い直しを繰り返しながら撮り進めるため、素材には無音・フィラー・言い直しが多く含まれる
（検証素材では 6:09 のうち半分以上が不要で、整えると 2:51 になった）。
「意味のある部分（企画・撮影）は人が、意味のない後処理は機械が」やる状態にしたい。

### 課題

| #   | 課題                                                             | 影響                                               |
| --- | ---------------------------------------------------------------- | -------------------------------------------------- |
| P-1 | 無音とフィラーを波形と耳で探して切っている                       | 素材の長さに比例して作業時間がかかる               |
| P-2 | 言い直しは直後とは限らず、数チャンク後に戻って話し直すこともある | どの版を残すか、全体を聞き直して判断する必要がある |
| P-3 | 撮影時に「カット」の合図を入れていない（入れても開始点が曖昧）   | 合図に頼った半自動化ができない                     |
| P-4 | 画面録画が可変フレームレート                                     | 単純に切ると区間の頭のフレームが欠け、音ズレする   |

### ゴール

- 録画を読み込むだけで、無音・フィラー・言い直しが**削除済みの状態**で編集画面が開く
- 人は文字起こしを読み、確信度の低い箇所と判定の怪しい箇所だけを確認・修正すればよい
- 結果を Premiere XML で書き出し、Premiere Pro で仕上げを続けられる
- ローカルで完結し、追加費用がかからない（言い直しの判定は `claude -p` をサブスクの範囲で使う）

## 2. ユーザーストーリー

利用者は講座の制作者本人（1 名）。優先度は MoSCoW。MVP = Must のすべて。

### 用語

- **録画ファイル**: 1 回の録画で生まれる mov ファイル
- **レクチャー**: 編集と書き出しの単位。順序付きの 1 本以上の録画ファイルで構成される。
  途中で録画を止め、別ファイルで途中から撮り直した場合は、それらのファイルを 1 つのレクチャーにまとめる

### Must（MVP）

- **US-01 自動解析**: 録画ファイルを指定すると、文字起こし（文字単位のタイミングと確信度付き）、無音検出、フィラー検出、
  言い直しの判定が自動で行われ、削除候補が**適用された状態**で編集画面が開く
- **US-02 3 ペイン表示**: 左に動画プレビュー、右に文字起こし、下に波形タイムラインを並べて表示する。
  削除区間を種類で色分けする（赤 = 無音、青 = フィラー、別の色 = 言い直し・言い損じ）
- **US-03 テキストで編集**: 文字起こしのテキストを Google ドキュメントの感覚で選択・削除すると、動画も同じ区間がカットされる。
  削除した区間（自動・手動とも）は復活でき、操作は取り消し（undo）・やり直し（redo）できる
- **US-04 要確認箇所の印**: 文字起こしの確信度が低い箇所に印を付け、そこだけ耳で確認すればよいようにする
- **US-05 判定理由の表示**: 言い直しで削除した区間には理由（例:「12 行後で言い直し」）を表示し、その場で採否を変えられる
- **US-06 カット後のプレビュー**: 削除区間を飛ばした完成形を、書き出す前にその場で再生して確認できる
- **US-07 Premiere XML の書き出し**: レクチャーのカット済みタイムラインを Premiere XML（FCP7 xmeml）で書き出し、
  Premiere Pro で読み込むと音ズレなく同じカットが再現される（可変フレームレート素材、複数の録画ファイルを含む）
- **US-08 編集状態の保存と再開**: 解析結果と編集状態を保存し、後で開き直しても再解析なしで続きから作業できる
- **US-09 MP4 の書き出し**: Premiere を通さずに、レクチャーのカット済み MP4 を直接書き出す（可変フレームレート素材でも音ズレしない）
- **US-10 まとめて解析**: 画面から複数の録画ファイル（またはフォルダ）を投入すると、解析が順番に実行される。
  進捗（待機中・解析中・完了・失敗）を一覧で確認でき、失敗したものは再実行できる。
  完了したものから「編集待ち」として一覧に並び、カットの確認・修正は 1 つずつ編集画面で行う。
  コマンドラインからも同じ投入ができる
- **US-11 ファイルをまたいだ撮り直し**: 一覧で複数の録画ファイルを選んで 1 つのレクチャーにまとめられる
  （並び順は録画日時が初期値で、手で入れ替えられる）。言い直しの判定はレクチャー全体を通して行い、
  前のファイルにある撮り直し前の版も削除候補にする。まとめ方を変えたときは判定だけをやり直す（文字起こしは再利用する）

### Should

- **US-12 まとめ方の提案**: ファイル名や録画時刻の近さから、同じレクチャーに属しそうな録画ファイルを提案する

### Could（将来）

- **US-13 テロップ・字幕**: 文字単位のタイミングを使って、テロップ用 XML と SRT を書き出す
  （MVP では実装しないが、**データモデルは最初からこれを前提に設計する**）
- **US-14 デスクトップアプリ化**: Tauri 等で包む（[ADR-001](./adr/ADR-001-language-and-stack.md) で保留）

## 3. 成功指標

二段階で評価する。開発中は正解データで自動計測し、最終的な合格判定は実際の撮影素材を使って人が行う。

### 3-1. 開発上の暫定指標（自動計測）

正解データ [`sample-judge-ground-truth.json`](./references/prototype/sample-judge-ground-truth.json)
（検証素材 6:09、69 チャンク中 21 を削除）に対する言い直し・言い損じ判定の一致度。
判定ルールは「最後に話した版を残す」「迷ったら残す」なので、**誤削除を削除漏れより重く見る**。

| 指標                                                       | 現状                                        | 目標（暫定・合意済み） |
| ---------------------------------------------------------- | ------------------------------------------- | ------------ |
| 削除判定の適合率（削除した区間のうち、正解でも削除の割合） | 未計測                                      | ≥ 90%        |
| 削除判定の再現率（正解の削除区間のうち、削除できた割合）   | 未計測                                      | ≥ 80%        |
| 解析時間（6 分の素材）                                     | whisper.cpp medium で文字起こしのみ約 70 秒 | ≤ 5 分       |

※ 正解データはチャンク（無音区切り）単位。パイプラインがより細かい単位で判定する場合は、時間の重なりで対応付けて計測する。

### 3-2. 受け入れ基準（人による精度チェック）

実際に撮影した講座素材 **3 本**を vid-cut で処理し、制作者本人が結果を確認して精度を判定する。
手作業の所要時間は、同じ素材（または同程度の長さの素材）を Premiere で手作業カットしたときの実績を基準にする。

| 観点             | 記録する内容                                                                 | 合格基準                         |
| ---------------- | ---------------------------------------------------------------------------- | -------------------------------- |
| 誤削除 | 講義として必要な発話が削除されていた箇所の数 | 素材 1 本あたり 2 件以下 |
| 削除漏れ | 削除すべきなのに残っていた箇所の数 | 記録のみ（直す手間は作業時間に含まれる） |
| 作業時間 | 素材の読み込みから Premiere XML の書き出しまでの時間（従来の手作業との比較） | 手作業の半分以下 |
| 書き出しの正しさ | Premiere で読み込んだときの音ズレ・フレーム欠けの有無                        | 0 件                             |

## 4. スコープ外

- 「カット」の合図（拍手・特定の言葉など）による区切り
- テロップ・字幕の書き出し（US-13。データモデルでの考慮のみ MVP に含む）
- Premiere 以外の NLE 向けの書き出し（Final Cut Pro、DaVinci Resolve 等）
- クラウド API・有料サービスの利用（`claude -p` のサブスク利用を除く）
- 複数話者の識別、日本語以外の言語
- 別々のレクチャー間での重複の検出（撮り直しの判定はレクチャー内に限る）
- 本人以外への配布・マルチユーザー対応
- 色調補正・ズーム・BGM などの仕上げ（Premiere で行う）

### 前提・制約

- 実行環境は macOS（Apple Silicon）のみ
- 前提ツール: ffmpeg、`claude` CLI（ログイン済み）
- 素材は可変フレームレートの画面録画（平均 3fps 程度）、AAC 48kHz、高解像度（例: 3104x1964）
