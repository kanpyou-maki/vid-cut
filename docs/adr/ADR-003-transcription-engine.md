# ADR-003: 文字起こしは mlx-whisper、位置合わせは WhisperX を使う

**ステータス:** 承認済み
**作成日:** 2026-10-03

## Context（背景）

必要なのは、日本語の文字起こしと、文字単位の時刻（テキスト編集とカット、将来のテロップ用）と、確信度（要確認の印）である。
環境は Apple Silicon の Mac で、費用をかけずローカルで完結させたい。

プロトタイプでは whisper.cpp（ggml-medium）で 6 分の音声を約 70 秒で処理した。
Whisper はフィラーを省いて書き起こす癖があるため、ヒント文にフィラーを含める対策を取る。

## Decision（決定）

- 文字起こしは **mlx-whisper**（モデルは large-v3-turbo）。無音で区切ったチャンクごとに実行する
  - `word_timestamps` は使わない（処理時間がほぼ倍になるため。時刻は位置合わせで取る）
  - 確信度は、チャンク単位の `avg_logprob` と、位置合わせの文字単位のスコアを組み合わせて使う
- 文字単位の時刻は **WhisperX の位置合わせ**（日本語は wav2vec2 の CTC）で付ける。合わせ込みのスコアも保存する
- どちらも `pipeline/ports.py` の `Transcriber` / `Aligner` の背後に置き、差し替えられるようにする

## Consequences（結果）

### ポジティブ

- Apple Silicon の GPU（MLX）で large 系のモデルを実用的な速度で動かせる見込み
- 文字単位の時刻が取れるので、テキストの選択範囲をそのままカット区間にできる

### ネガティブ

- WhisperX は PyTorch に依存し、セットアップが重い。Apple Silicon の GPU（MPS）では動かない部分があり、CPU 実行になる可能性がある
- 2 つのモデルをメモリに載せる。worker は 1 件ずつ処理するので許容範囲と見込む

## スパイク S-2・S-3 の結果（2026-10-03、検証素材 6:09・69 チャンク）

| 項目 | 結果 |
|------|------|
| 文字起こし（mlx-whisper large-v3-turbo、チャンクごと） | `word_timestamps` ありで 186 秒、**なしで 99 秒**。モデルの読み込みはキャッシュ済みなら 2 秒（初回はダウンロードで約 4 分） |
| 比較（whisper.cpp medium、プロトタイプ） | 約 70 秒 |
| 精度 | turbo の方が明らかに良い（例: 「パストラバーサロ」→「パストラバーサル」、「プライアント」→「クライアント」、「買い物過後」→「買い物カゴ」）。固有の誤りは残る（「秘伝項目」など） |
| 位置合わせ（WhisperX、日本語 wav2vec2、CPU） | 21 秒。1,519 文字すべてに時刻が付き、スコアの平均は 0.90。モデルの読み込みは初回のみ約 1 分 |
| Python 3.12 + Apple Silicon での導入 | `uv pip install mlx-whisper whisperx` で問題なく動作（torch 2.8.0） |
| 確信度と削除の関係 | 確信度の低いチャンク（`avg_logprob` < -0.5）7 件のうち 4 件（6, 10, 14, 32）が正解データの削除対象（言い損じ）。要確認の印として有効な見込み |
| フィラー | 両エンジンとも 0 件。ユーザーが聞いて確認した結果、**検証素材にはフィラーがない**（言い直しは多い）。フィラーの書き起こし精度は未検証 |

結論: 精度を重視して mlx-whisper large-v3-turbo を採用する。whisper.cpp large-v3 との比較は、turbo の精度と速度が要件を満たすため省略した。

## Alternatives Considered（検討した代替案）

### 案 A: whisper.cpp

既にローカルにあり、速度も確認済み。Python からはサブプロセスかバインディング経由になり、トークンの確率の取り出しが mlx-whisper より手間がかかる。
スパイク S-2 で mlx-whisper の精度か速度が明らかに劣れば、こちらにする。

### 案 B: faster-whisper（CTranslate2）

kickoff で名前が挙がっていたが、Mac では GPU を使えず CPU 実行になり遅い。採用しない。

### 案 C: Whisper の単語タイムスタンプだけを使う（位置合わせなし）

依存は軽くなるが、日本語では時刻の精度が粗く、カット点がずれる。採用しない。
