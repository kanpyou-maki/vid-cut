# キックオフ資料 — work-repo からの引き継ぎ

このリポジトリは、雑務モノレポ `~/Projects/work-repo` の `tasks/udemy-video-cut/` で行った検討とプロトタイプ検証から昇格したもの（2026-10-03）。
bootstrap と PRD 作成の入力として使う。

## 目的
Udemy 用に録画した mov（画面録画 + ナレーション、日本語）から、**無音・フィラー・言い直しを自動検出してカット**する。
これまでは Premiere Pro で手作業でカットしていた。
「意味のある部分（企画・撮影）は人が、意味のない後処理は機械が」やる。

## イメージ（目標水準）
YouTuber「クウキデザイン」が自作した **VidTighten** に近いもの。ソースは非公開。
- 左にプレビュー動画、右に文字起こし、下に波形タイムライン
- 自動削除した区間を色分けして表示する（赤 = 無音、青 = フィラー）
- 文字起こしのテキストを Google ドキュメントの感覚で選択・削除すると、動画も同時にカットされる
- 文字起こしの確信度が低い箇所に印を付け、そこだけ耳で確認すればよいようにする
- Faster-Whisper で文字起こしし、WhisperX で単語単位の位置合わせ。ローカルで完結し、費用はかからない
- カット済みタイムラインの XML とテロップ用 XML を書き出し、NLE（動画編集ソフト。VidTighten では Final Cut Pro）で仕上げる

**このプロジェクト独自の強み**: **言い直しの自動検出**（Claude で判定）。VidTighten は無音とフィラーが中心。

## ユーザー決定事項
| 項目 | 決定 |
|---|---|
| 置き場所 | 専用リポジトリ（ここ） |
| 仕上げ | **Premiere Pro に読み込んで仕上げる → Premiere XML（FCP7 xmeml）の書き出しを優先**。MP4 の直接書き出しは補助 |
| テロップ | MVP からは外す。ただし**将来必要になる確度は高い** → データモデルは字幕（単語単位タイミング）を前提に設計しておく |
| 「カット」の合図 | **使わない**。撮影済み動画が複数ある。良いと思って撮影を続けた後で話し直すこともある。合図があってもカット開始点は明確にならない |
| 費用 | 有料ソフトへの課金は避けたい（絶対条件ではない）。言い直しの判定は `claude -p`（サブスクの範囲内）で行う方針 |

## 推奨構成（案。設計フェーズで確定させる）
- 文字起こし: mlx-whisper（Apple Silicon）+ WhisperX の位置合わせ（日本語は wav2vec2 による文字単位の合わせ込み）で、文字単位のタイミングと確信度を取る
  - Whisper はフィラー（「えー」「あのー」）を省いて書き起こす癖がある。対策として、最初に渡すヒント文にフィラーを含めて書き起こさせる
- 無音検出: Silero VAD と音量の併用
- 言い直しの判定: `claude -p` に発話のまとまりを渡し、JSON で削除対象を受け取る（プロトタイプの判定指示を流用）
- 画面: ローカル Web アプリ（Python/FastAPI + React/Vite）。必要になったら Tauri でデスクトップアプリ化する
- 書き出し: Premiere XML、MP4、（将来）SRT とテロップ

## プロトタイプで判明したこと（`prototype/udemy_cut.py`）
- 検証素材: `~/Desktop/s05-12sample.mov`（6:09、3104x1964、**可変フレームレート**、AAC 48kHz）
- **無音で分割したチャンクごとに文字起こしする**方が、全体を一括で文字起こしするより精度が高い。
  一括だと、区切りが無音をまたぐうえ、無音区間に幻聴（実在しない文）も出た
- 無音は -40dB・0.3秒以上の閾値で 69 チャンクに分割できた。発話のピークは約 -16dB、無音区間は -43dB 以下
- 言い直しの判定（手動での正解データ）: 69 チャンク中 21 を削除し、6:09 → 2:51 になった。正解は `prototype/sample-judge-ground-truth.json`
  - 言い直しは直後とは限らない。数チャンク後に戻って話し直す例や、3回言い直す例があった
  - 判定ルールは「最後に話した版を残す」「迷ったら残す」
- **画面録画は可変フレームレート**（平均 3fps 程度）。そのまま切ると区間頭のフレームが欠けて音ズレするので、`fps=60` で固定化してから切る
  - Premiere XML で書き出す場合も、可変フレームレートの素材の扱いに注意する
- `h264_videotoolbox -q:v 60` なら画質は十分で、サイズは 97MB（固定 12Mbps だと 209MB）
- whisper.cpp（`~/Projects/whisper.cpp`、ggml-medium）は 6分の音声を約70秒で処理。large モデルのファイルは空（未ダウンロード）
- `claude -p` は検証時に OAuth の期限切れで失敗した。`claude` → `/login` で再ログインが必要
